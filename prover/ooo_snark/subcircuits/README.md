This folder contains the following components:

1. **Input Buffer**: This buffer can receive up to 8 inputs.
2. **Output Buffer**: This buffer includes 32 outputs.
3. **32-bit Bitify Circom**: This component is responsible for converting inputs into 32-bit format.
4. **32-bit Integer Addition**: This component handles the addition of two 32-bit integers.
5. **32-bit Integer Multiplication**: This component handles the multiplication of two 32-bit integers.
